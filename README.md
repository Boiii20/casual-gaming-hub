Casual Gaming Hub
A web-based arcade application featuring seven interactive browser games, built on a unified single-page architecture with a modern dark theme.

Project Overview
This application was developed as an academic school project. In alignment with classroom guidelines, artificial intelligence tools were utilized to assist with software development, logic structure, and optimization. As this project serves an educational purpose and represents an exploratory development workflow, minor edge-case bugs may be present.

Features
Integrated Game Suite: Includes Tic-Tac-Toe, Rock-Paper-Scissors, Number Guesser, Snake, Whack-a-Mole, 2D Pong, and a 2D Tank Survival RPG.

Automated Opponents: Rule-based and adaptive logic implementations for single-player modes.

Cross-Platform Compatibility: Responsive layout supporting standard desktop keyboard/mouse navigation alongside mobile touch controls and directional pads.

Native Audio Engine: Browser-level sound synthesis powered by the Web Audio API without reliance on external asset dependencies.

Full-Screen Capability: Native HTML5 Fullscreen API integration for uninterrupted display across desktop and mobile devices.

Technology Stack
Backend Framework: Python, Flask

Frontend Technologies: HTML5 (Canvas), CSS3, Vanilla JavaScript

Development Assistance: Gemini AI
